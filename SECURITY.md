# InputBridge Security Policy

InputBridge is an experimental macOS input-mapping project.

## Reporting vulnerabilities

Please privately report suspected vulnerabilities to:

jahvascripts@gmail.com

Do not post credentials, private user data, or
sensitive exploit details in public GitHub issues.

## Important limitations

InputBridge uses macOS input-monitoring permissions.
Review its source and permissions before use.

Simulation mode does not create a working system-wide
virtual game controller.

Virtual DS4 mode requires Apple's authorized virtual-HID
entitlement and has not been validated with PS Remote Play.

The software has not received an independent security audit.
